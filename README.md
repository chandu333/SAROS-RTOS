# SAROS — Secure Automotive Real-Time Operating System

SAROS is a cybersecurity-native RTOS designed for automotive ECUs.

Unlike traditional RTOS platforms, SAROS enforces security at the kernel level.

Key capabilities include:

• Secure Boot
• SecOC-authenticated IPC
• Secure Debug
• Secure Flashing
• Tamper-proof audit logs

The architecture follows a microkernel-based design with a portable cryptographic abstraction layer compatible with automotive HSMs.
